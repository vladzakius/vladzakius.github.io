# v42 — рік фільму як обов'язкова умова

Проблема: пошук включав рік картки, але ранжування приймало також оригінали/ремейки з іншого року. Наприклад, для «Згадати все» (2012) могла запускатися версія 1990 року.

Зміни:
- Для фільму з відомим роком реліз повинен підтверджувати саме цей рік у назві або полі Year/year/release_year.
- Інший, невідомий або суперечливий рік відсіюється до підключення TorrServe. Кількість сідів і запасна якість не обходять перевірку.
- PublishDate не використовується: це дата публікації роздачі.
- Назви відеофайлів перевіряються повторно; явно інший рік відсіюється. Файл без року допустимий лише після підтвердження року релізу.
- Захист працює також при прямому виклику відтворення.
- Ця перевірка не застосовується до серіалів: рік сезону може відрізнятися від прем'єри.
- Діагностика окремо показує непідтверджений або неправильний рік.

Перевірка: 186 автоматичних тестів (13 нових), Node syntax, ES5 Acorn, git diff --check. Є окремий сценарій Total Recall 1990/2012, суперечливі метадані, невідомий рік, перевірка файлів та серіали. Реальний телевізор не тестувався.

Обмеження: це перевірка року, а не повна ідентифікація за IMDb/TMDB. Помилкова назва у джерелі або різні фільми з однаковими назвою й роком потребують додаткових ідентифікаторів. Релізи без підтвердженого року та неоднозначні збірки не запускаються автоматично. Для карток без року старий механізм підбору збережено.
