# «Дивитись» v39: аудит і виправлення

Перевірено всі основні шляхи плагіна: налаштування, пошук, об’єднання результатів, мову, рейтинг, сезони, файли, TorrServe, буферизацію, запуск, повторні спроби, плейлист, історію та інтеграцію кнопок. Перебудовано вибір кандидатів і керування відтворенням. Для встановлення, як і раніше, потрібен лише `b.js`.

## Проблеми та результат

| Проблема з попередніх версій | Зміна v39 | Перевірка |
| --- | --- | --- |
| У звичайному пошуку є релізи, а кнопка їх не бачить | Використовується налаштований `Lampa.Parser.get`, включно з його джерелами. Для старих збірок — Jackett і вибрана основна/друга адреса. Назви запитуються українською, російською та мовою оригіналу | Тести API парсера, альтернативних назв, дедуплікації, таймаутів |
| RUS видно в Lampa, але плагін вважає мову невідомою | Читаються аудіопотоки `ffprobe`; субтитри не вважаються озвучкою. Явний код мови важливіший за назву релізу й підпис доріжки | Синтетичні ffprobe та події tracks |
| Обрано українську, грає російська | Строгий режим допускає лише релізи із заявленою українською. Якщо вбудований плеєр повідомляє доріжки без української, автоматично перевіряється наступний кандидат | Відбір, змішані/російські доріжки, суперечливі метадані |
| Запасна якість змінює мовний пріоритет | Мова — окремий рівень сортування, її не переважують роздільність, бітрейт чи сіди | UKR 720p/1 сід проти RUS 1080p/900 сідів |
| Сезонні паки ховають усі одиночні серії | Паки мають пріоритет, але одиночні релізи зберігаються як запасні | Помилка паку → одиночна серія |
| При повторі запускається інша серія | Серія зіставляється за номером, а не позицією в масиві. Немає потрібного номера — кандидат пропускається | Різний порядок, неповні паки, невідповідний сезон |
| Помилка доступу до сервера виглядає як «немає живих роздач» | Окремі повідомлення про доступ, мережу, метадані та плеєр; термінальна помилка сервера зупиняє перебір | HTTP 401/403/404/500, JSON, timeout, скасування |
| Плеєр завис на старті | Вбудований плеєр без поступу 25 секунд після готовності переходить до наступного кандидата. Пауза або ручне закриття не запускають повтор | Події ready/timeupdate/pause/destroy |
| Невдалий запуск потрапляє в історію | Для вбудованого плеєра запис після поступового просування відео; кожна наступна серія має свої обробники | Історія, зміна серій, повторні помилки |
| Ліміт розміру обходиться | Ліміт фільму обов’язковий; сезонні паки ним не обмежуються. Роздільність і сіди — бажані значення із запасними варіантами | Ліміти, одиниці, нуль, авто, сезони |
| `undefined` або старі обробники після оновлення | Міграція налаштувань, видалення дубльованих параметрів, перев’язування кнопок і меню, скасування старих операцій | DOM-тести запуску й оновлення версії |

## Порядок автоматичного вибору

Обов’язкові перевірки: заборонені джерела/3D/HDR відповідно до налаштувань, наявність посилання, ліміт розміру фільму та українська у строгому режимі. Далі: мовний пріоритет → оцінка сумісності кодека → сезонні паки → бажана якість/сіди → рейтинг. Під час запуску перевіряються файли й сезон, при повторі зберігається потрібна серія.

За один пошук перевіряється до шести варіантів назви, одночасно до двох пошукових запитів; кожен може використовувати декілька джерел Lampa. До 12 кандидатів на відтворення. Метадані очікуються до 20 секунд, підготовка буфера — до 12 секунд. Обмеження не є гарантією загального часу: діалоги вибору сезону/серії, зовнішнього плеєра та мережеві затримки окремі.

| Налаштування мови | Поведінка |
| --- | --- |
| Українська (обов’язково) | Без автоматичної підміни іншою мовою; невідома мова відсіюється до запуску |
| Українська → російська | Спочатку UKR, потім RUS, потім невідомі запасні варіанти |
| Російська → інші | Спочатку RUS, потім невідомі, потім інші визначені мови |
| Байдуже | Мова не впливає на рейтинг; доріжкою керує плеєр |

Назви пунктів уточнено; внутрішні ключі збережено. Старі значення «староукраїнська» продовжують працювати як російський пріоритет.

## Пристрій та реальні межі

Автоматична оцінка використовує розміри екрана, pixel ratio, HDR media queries, `canPlayType` і метадані відео. Без надійних підказок обирається безпечніший H.264. Сумісність має вищий пріоритет за бонуси якості. Ручні налаштування збережено.

Це не апаратна сертифікація: API браузера не описує всі можливості декодера, контейнера, зовнішнього плеєра або телевізора. Плагін не перекодовує відео й не додає відсутню озвучку.

Мова в назві або ffprobe індексатора може бути помилковою. Остаточне перемикання доступне, коли вбудований плеєр надає подію `tracks`. Якщо пристрій не повідомляє доріжки, залишається відбір за метаданими; достовірність фактичної доріжки не гарантовано. Зовнішній плеєр керує доріжками сам; передача йому посилання не позначається як перевірене відтворення. В історії така передача має `verified: false`.

Позиція при переході на інший реліз приблизна, якщо монтаж або вступ відрізняються. Старі записи історії читаються; нові ключі відокремлюють джерела, типи карток і серії. Непозначені файли в багатосезонному паку пропускаються, щоб не запускати випадковий сезон.

## Перевірки

Виконано 131 автоматичну перевірку: регресійні сценарії з підробленою мережею/метаданими та DOM-тести з JSDOM і jQuery. Перевірено ES5-синтаксис Acorn, обидві розмітки картки, повторне завантаження плагіна, зміну версії та всі кнопки діагностики. Медіапрогравання на фізичному телевізорі/iPhone цим тестуванням не замінюється.

Відтворюваний запуск (Node.js 20+):

```sh
npm ci --ignore-scripts
npm test
```

Лише регресійні сценарії, без встановлення dev-залежностей:

```sh
npm run test:core
```

Інтеграцію зіставлено з вихідним кодом [Lampa](https://github.com/yumata/lampa-source/tree/b4a13b6af7fe2f3bbbcb91f4eb434ab3378f8d5d): Parser, Player, PlayerVideo, Timeline, SettingsApi та Subscribe. Формат запитів зіставлено з API [TorrServer](https://github.com/YouROK/TorrServer).

## Оновлення та діагностика

Перезапусти Lampa; має з’явитися «Дивитись v39 активний». Якщо залишилася стара версія через кеш, заміни адресу існуючого плагіна на `https://vladzakius.github.io/b.js?v=39`, не додаючи другу копію.

У «Найкраща якість» додано «Остання перевірка» — кількість знайдених релізів, кандидатів, спроб і причини відмов — та «Зупинити автоматичний пошук». Дані діагностики тримаються лише в поточному сеансі й не містять паролів чи API-ключів. «Перевірити з’єднання» перевіряє HTTP-доступність; фактичний перегляд перевіряється окремо за подіями плеєра.
