# «Дивитись» v38

Виправлено непогоджену підміну української озвучки іншою мовою.

- «Українська» допускає лише релізи з українськими мовними позначками в назві або явних аудіометаданих. Невідомі та російські варіанти не додаються після відмови українського кандидата.
- Запасний підбір якості не послаблює український мовний фільтр.
- «Українська → староукраїнська» й надалі дозволяє російський запасний варіант; «Байдуже» не фільтрує за мовою.
- Явні аудіометадані мають перевагу над мовними позначками назви.
- Коли Lampa PlayerVideo надає список аудіодоріжок, плагін вмикає українську доріжку. Якщо список містить лише відомі інші мови, цей кандидат відхиляється автоматично.
- Збережене продовження без підтвердженої української мови повторно шукається в українському режимі.

Перевірено синтаксис і 54 автоматичні сценарії (`node --check b.js`, `node --test tests/b-reliability.test.cjs`). Тести використовують штучні дані, без реальних роздач.

Позначки індексатора не є перевіркою звукового вмісту. Зовнішні плеєри керують аудіодоріжками самостійно й можуть не надавати їх список Lampa; автоматичне перемикання доріжки у такому плеєрі не гарантується. Вбудований плеєр також може не показати мовні метадані для окремого контейнера.
